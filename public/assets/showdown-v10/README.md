# Psychic Vault artwork and Spine effects

V10 uses generated raster artwork, exported as PNG assets, with externally loaded Spine4.2 meshes and bone timelines. No PixiGraphics or Canvas painting generates the chamber, flames, shield, summon, portal, card frame, or ground shadows. SolidSprite fades and native Text remain ordinary UI/compositing.

- `chamber.png` / `chamber-portrait.png`: separately composed environment artwork.
- `jet.png`, `ward.png`, `summon.png`, `reward.png`, `shadow.png`: isolated original generated artwork.
- `effects.png` / `support.png`: source artwork sheets; atlas metadata selects supporting regions.
- `vault.atlas`: multi-page original-PNG region metadata.
- `vault.json`: external Spine4.2 skeleton, generated by `scripts/build-painted-vault-spine.mjs` (geometry/timelines only).

Pokémon retain their existing native skeletal3D animation; they are not newly authored Spine character rigs. Spine is used for the raster effects. Mock trigger/outcome logic is unchanged.
